Never forward port 8443 on your router — anyone who can reach this page can enroll a device.

Enroll a device

Scan the QR in the Sambaloader app, then check the fingerprint the app shows matches the one below before confirming. The code is single-use and expires in 10 minutes.

You can do the same from a terminal with docker compose exec uploadd /uploadd -pair.
